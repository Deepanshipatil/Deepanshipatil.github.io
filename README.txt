DEEPANSHI PATIL — BOOTSTRAP PORTFOLIO

How to use:
1. Extract this ZIP.
2. Open the folder in VS Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. Edit index.html/style.css if you want to customize text or colors.
5. The resume and profile photo are already included in assets/.

Bootstrap 5.3.3, Bootstrap Icons and AOS are loaded from CDNs, so an internet connection is needed when viewing the site unless you download those libraries locally.

Your GitHub and LinkedIn links are already connected.
